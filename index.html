ทดสอบเชื่อมต่อ API ราคา

หน้าทดสอบแยกต่างหาก ไม่เกี่ยวกับ MISSION CONTROL ไม่แตะข้อมูลของคุณ ไม่มีราคาจำลองในหน้านี้: ตัวเลขที่เห็นคือสิ่งที่ API ตอบกลับมาจริงเท่านั้น

อ่านก่อนวาง API key

  • คีย์ที่วางจะถูกส่งจากเบราว์เซอร์ของคุณตรงไปยังผู้ให้บริการ (CoinGecko, Finnhub, Twelve Data) ผ่าน HTTPS ไม่ผ่านผมและไม่ผ่านเซิร์ฟเวอร์อื่น
  • หน้านี้ไม่บันทึกคีย์ไว้ที่ใดเลย (ไม่ใช้ localStorage) ปิดหน้าหรือรีเฟรชแล้วคีย์หาย
  • คีย์อยู่ใน URL ของคำขอ จึงมองเห็นได้ในเครื่องมือนักพัฒนาของเบราว์เซอร์ และผู้ให้บริการอาจเก็บลงบันทึกของเขา
  • ห้ามใส่คีย์ลงในไฟล์ใน GitHub repository สาธารณะ ใครก็ดูได้ และอย่าส่งคีย์หรือภาพหน้าจอที่เห็นคีย์ในแชต
  • ใช้คีย์ฟรีที่สร้างใหม่สำหรับทดสอบโดยเฉพาะ คีย์เหล่านี้อ่านราคาได้อย่างเดียว ไม่แตะเงินหรือบัญชีซื้อขาย ถ้าสงสัยว่ารั่ว ให้ลบแล้วสร้างใหม่ที่เว็บผู้ให้บริการ
  • เพื่อลดความเสี่ยง หน้านี้ตั้งนโยบายให้ส่งข้อมูลออกได้เฉพาะ 5 โดเมนที่ทดสอบเท่านั้น
